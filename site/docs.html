Documentation

Learn how to generate production-ready MCP (Model Context Protocol) servers in minutes, without writing code.

What is MCP Builder?

MCP Builder is a tool that lets you generate production-ready MCP servers. You just configure what you want to connect, pay, and receive a .zip file with the complete server and installation documentation.

No accounts or sign-ups

The flow is guest-only. You pay, download, done. No user to create, no passwords.

Installing the generated server

Once you download the .zip file, follow these steps:

1. Extract and install dependencies

# Extract the archive
unzip server.zip
cd server

# Install dependencies
npm install

2. Configure Claude Desktop

# File: ~/Library/Application Support/Claude/claude_desktop_config.json
# On Windows: %APPDATA%\Claude\claude_desktop_config.json
{
  "mcpServers": {
    "my-server": {
      "command": "node",
      "args": ["./server/index.js"]
    }
  }
}

3. Restart Claude Desktop

Close and reopen Claude Desktop. The MCP server will appear automatically in the tools list.

Configuration options

Parameter Type Description
source string Source type: local, database, api
tables string[] Allowed tables (database only)
permissions string read, write, full
rules string Custom security rules

Local Files

Connect your AI to files on your machine. Supports .csv, .json, .txt, .md.

# Example: server for CSV files
source: local
path: "./data"
types: [".csv", ".json"]

Databases

PostgreSQL, MySQL, MariaDB. SQL queries generated by the AI with security validation.

# Example: PostgreSQL connection
source: database
host: "localhost:5432"
database: "my_db"
tables: ["users", "orders"]
permissions: "read"

Security

Dangerous queries (DROP, DELETE, TRUNCATE) are blocked by default. Permissions are configurable.

External APIs

Connect your AI to any REST or GraphQL API. Auth with API key, OAuth2 or Bearer token.

# Example: REST API connection
source: api
baseUrl: "https://api.example.com"
auth: {
  "type": "bearer",
  "token": "your-token"
}
endpoints: ["/products", "/orders"]

Troubleshooting

The server does not appear in Claude Desktop

Check that the path in the configuration file is absolute. Fully restart Claude Desktop (quit it from the system tray, not just the window).

Database connection error

Check that the database accepts connections from your IP. Review the host, port, user and password in the configuration.

The external API does not respond

Check that the base URL is correct and that the token or API key has the required permissions. The server includes detailed logs for debugging.

Frequently asked questions

What does the downloaded file include?

The .zip file contains: an MCP server in TypeScript, a package.json with dependencies, a README with step-by-step instructions, and production-ready configuration.

Is it compatible with Cursor and Windsurf?

Yes. The generated MCP server follows the MCP standard and works with any compatible client: Claude Desktop, Cursor, Windsurf and more.

Do I need Node.js installed?

Yes, Node.js 18+ is required to run the MCP server. You can download it from nodejs.org.
