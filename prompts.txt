1. EL MODELO DE NEGOCIO (B2B SaaS)
- Producto: Generador de servidores MCP (Model Context Protocol) listos para producción.
- Monetización: Pago único por generación (Guest Checkout) usando Stripe.
- Diferenciador: Cero fricción, sin inicio de sesión (Login), 100% código local y seguro.

2. EL STACK TECNOLÓGICO ($0 COSTO)
- Frontend: HTML/CSS/JS Estático (Alojado en Cloudflare Pages o Netlify).
- Backend: Python / FastAPI (Alojado en Koyeb o Railway).
- Base de Datos: Neon.tech (PostgreSQL) o Supabase (Solo para guardar ID de compra y correo).
- Pasarela: Stripe (Modo de prueba).
- Cerebro IA (En cascada por si hay límite de tasa, con timeout de 5s):
  1. Together AI (Principal)
  2. Groq (Secundario)
  3. OpenRouter / Gemini 1.5 Flash (Respaldo)

3. LAS 4 RUTAS DEL BACKEND (FASTAPI)
- GET /api/v1/mcp-templates (Devuelve el catálogo: Local $5, DB $15, API $20).
- POST /api/v1/checkout (Se conecta a Stripe y genera el link de pago).
- GET /api/v1/success (Ruta a la que Stripe redirige al cliente tras pagar).
- POST /api/v1/generate-mcp (⭐️ EL MOTOR: Llama a la IA con el Prompt Maestro, inyecta el código en la plantilla y devuelve el .zip).
